# kid-wechat-guard（微信内小程序/视频号守护）

> 面向荣耀智慧空间用户的补位工具：当微信里的小程序、视频号成为孩子绕开防沉迷的通道时，由本 App 在**微信内层**做检测与拦截。系统层（应用限额、禁"设置"）继续交给荣耀智慧空间。

## 当前状态

- [x] 需求与方案讨论（见 `docs/design.md`）
- [ ] P1 本机原型（小程序/视频号检测 + 配额 + 缓冲 + 锁定）
- [ ] P2 远程审批与失联告警（可选，暂缓）
- [ ] P3 开源加固（可选）

## 关键约束速记

- 设备：荣耀，MagicOS 9.0 / Android 15
- 只做"微信内层"，不重复智慧空间的能力
- P1 授权为本机家长密码；为远程审批预留接口
- 默认配额：学习日 30 分钟 / 周末 60 分钟；缓冲 5 分钟（均可配置）
- 每个内层类别（小程序/小游戏、视频号）都可选 `禁止` 或 `时长限额`；默认：视频号=禁止，小程序/小游戏=限额

详细设计见 [`docs/design.md`](docs/design.md)。
